# ROS2 Transform Trees and Odometry

!!! info "Preliminary version"
    This is a concise English version. See the Japanese page for the full detailed walkthrough.

## Learning Objectives

Publish camera poses to the TF tree, publish relative poses, set up robot odometry, and view the TF tree inside Isaac Sim.

Two publisher nodes: **ROS2 Publish Transform Tree** reads actual prim poses (an articulation root target publishes all descendant links); **ROS2 Publish Raw Transform Tree** publishes one parent→child transform, for logical frames like `odom -> base_link`.

## Transform Tree Publisher

Add a **ROS2 Publish Transform Tree** node (with On Playback Tick and Isaac Read Simulation Time), put `Camera_1`/`Camera_2` in `targetPrims`, verify with `ros2 topic echo /tf`. Transforms default to the world frame; set `parentPrim` (e.g. `Camera_1`) for relative transforms (stop/play between property changes). If the wrong root link is chosen for an articulated robot, delete the Articulation Root in Raw USD Properties and re-add it (+ADD > Physics > Articulation Root) on the desired prim, then save and reload.

## Setting Up Odometry

1. Ensure the articulation root is `/World/turtlebot3_burger`.
2. Build the odometry graph: **Isaac Compute Odometry Node** (Chassis Prim = robot prim; computes pose relative to start) feeding a **ROS2 Publish Odometry** node (chassisFrameId `base_link`, odomFrameId `odom`) and a **ROS2 Publish Raw Transform Tree** (parent `odom`, child `base_link`). The odometry message carries full 3D linear and angular velocity.
3. Add a **ROS2 Publish Transform Tree** with parentPrim `/World/turtlebot3_burger/base_link` and targetPrims for base_footprint, base_scan, caster_back_link, imu_link, wheel_left_link, wheel_right_link.
4. Optional ground-truth localization: another Raw TF node with parent `world`, child `odom` (defaults = start pose). Normally a localization package such as Nav2 AMCL provides this transform.

Verify with `ros2 run tf2_tools view_frames`.

![Final odometry graph](https://docs.isaacsim.omniverse.nvidia.com/5.1.0/_images/isim_5.0_ros_tut_gui_ros2_odometry_graph_final.png)

Menu shortcuts: **Tools > Robotics > ROS 2 OmniGraphs > TF Publisher / Odometry Publisher**.

## TF Viewer

Enable `isaacsim.ros2.tf_viewer`, open **Window > TF Viewer**, choose the root frame — the published `/tf` / `/tf_static` tree is drawn directly in the viewport. If nothing shows: play the sim first, reopen the window, or press Reset.
