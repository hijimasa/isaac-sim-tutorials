# カスタム C++ ノード

## 学習目標

このチュートリアルを修了すると、以下の内容を習得できます：

- C++ ノードと Python ノードの共通点・相違点
- カスタム C++ ノードを使うために必要な作業

## はじめに

### 前提条件

- [カスタム Python ノード](03_custom_python_nodes.md) で `.ogn` の書き方を理解していること
- C++ の基礎と Kit 拡張機能のビルド環境があること

### 所要時間

約 5 分

### 概要

C++ ノードの場合も、**ノード定義（`.ogn`）は [カスタム Python ノード](03_custom_python_nodes.md) と同じ**ものを使います。異なるのは、動作を定義する実装が C++ になる点です。

OmniGraph ノードを組み込む方法の例は、拡張機能テンプレートの GitHub リポジトリで確認できます。

## カスタム C++ ノードを使うには

カスタム C++ ノードを使うには、カスタム C++ 拡張機能を**ビルド**する必要があります。詳しい手順は Kit C++ Extension Template のドキュメントに従ってください。

!!! tip "Python ノードとの使い分け"
    - **Python ノード** … 手軽に作成でき、ビルド不要。プロトタイピングや軽量な処理に向いています。
    - **C++ ノード** … ビルドが必要ですが、計算負荷の高い処理でパフォーマンス上の利点があります。

## まとめ

このチュートリアルでは、次の内容を学びました。

- C++ ノードの `.ogn` 定義は Python ノードと同じであること
- カスタム C++ ノードを使うには C++ 拡張機能のビルドが必要であること
- 実装例は拡張機能テンプレートの GitHub リポジトリと Kit C++ Extension Template を参照すること
