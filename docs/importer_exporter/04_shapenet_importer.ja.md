# ShapeNet インポーター

!!! warning "非推奨（Deprecated）"
    ShapeNet 専用インポーターエクステンション `omni.isaac.shapenet` は**非推奨**となり、廃止されました。公式チュートリアルページにも現在はこの非推奨の告知のみが記載されています。ShapeNet モデルをインポートする場合は、通常の OBJ ファイルと同じ手順でインポートしてください。

## 学習目標

このチュートリアルを修了すると、以下の内容を習得できます：

- ShapeNet データベースの概要
- ShapeNet モデルを OBJ ファイルとして Isaac Sim にインポートする代替手順
- インポート後に物理プロパティを設定してシミュレーションで使う方法

## はじめに

### 前提条件

- Isaac Sim の基本操作に慣れていること
- [チュートリアル 1: URDF インポート](01_import_urdf.md) などで **File > Import** の操作を経験していること

### 所要時間

約 5 分

### 概要

ShapeNet は、椅子・テーブル・車など日常的な物体の 3D モデルを大量に収録した研究用データセットです。かつては Isaac Sim に専用のインポーターエクステンションが用意されていましたが、現在は非推奨となっています。このページでは、代替となる標準の OBJ インポート手順を紹介します。

## 推奨される代替手順

### 1. モデルをダウンロードする

[ShapeNet](https://shapenet.org/) のサイトからモデルをダウンロードします（利用にはアカウント登録と利用規約への同意が必要です）。ShapeNet のモデルは主に OBJ 形式（`.obj` ＋ `.mtl` ＋テクスチャ）で提供されます。

### 2. OBJ ファイルとしてインポートする

1. **File > Import** を開き、ダウンロードした `.obj` ファイルを選択します。
2. インポートオプション（スケール、マテリアルの取り込みなど）を確認して実行すると、モデルが USD に変換されてステージに追加されます。

!!! tip "スケールに注意"
    ShapeNet のモデルは正規化された単位（1 前後の大きさ）で保存されていることが多く、実寸とは一致しません。インポート後に実際の物体サイズに合わせてスケールを調整してください。

### 3. 物理プロパティを設定する

インポートした直後のモデルは見た目だけの存在で、物理シミュレーションには反応しません。シミュレーションで使うには：

1. モデルのプリムを選択し、Properties パネルの **+Add** ボタンから **Physics > Rigid Body with Colliders Preset** を適用します（動かない障害物として使う場合は **Colliders Preset** のみ）。
2. 必要に応じて質量やマテリアル（摩擦係数など）を設定します。

物理プロパティの設定方法の詳細は [Core API チュートリアル 7: 属性の追加](../core_api/07_adding_props.md) を参照してください。
