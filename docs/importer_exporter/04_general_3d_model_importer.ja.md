# 一般 3D モデルのインポート

## 学習目標

このチュートリアルを修了すると、以下の内容を習得できます：

- OBJ / FBX などの一般的な 3D モデルファイルを Isaac Sim にインポートして USD に変換する方法
- インポート時の単位・スケール・軸方向の扱い
- インポートしたモデルに物理プロパティ（Rigid Body / Collider）を設定してシミュレーションで使う方法

## はじめに

### 前提条件

- Isaac Sim の基本操作に慣れていること
- [チュートリアル 1: URDF インポート](01_import_urdf.md) などで **File > Import** の操作を経験していること

### 所要時間

約 5〜10 分

### 概要

ロボット記述形式（URDF / MJCF）以外にも、Isaac Sim は OBJ・FBX・glTF などの一般的な 3D モデル形式をインポートできます。障害物・什器・小物などをシーンに配置したいときに使う、最も汎用的なインポート経路です。

このチュートリアルでは、OBJ ファイルを例に「インポート → 単位・スケール調整 → 物理プロパティ設定 → シミュレーション」の一連の流れを解説します。

!!! note "ShapeNet などの 3D モデルデータセットについて"
    かつて Isaac Sim には ShapeNet データベース専用のインポーターエクステンション（`omni.isaac.shapenet`）がありましたが、**非推奨となり廃止されました**。ShapeNet を含む各種データセットのモデルも、本ページの手順（標準のファイルインポート）でインポートできます。

## ステップ 1：モデルファイルを用意する

インポートしたい 3D モデルファイル（`.obj`、`.fbx` など）を用意します。OBJ 形式の場合、通常は `.obj` 本体に加えてマテリアル（`.mtl`）とテクスチャ画像がセットになっています。ファイル一式を同じフォルダに置いてください。

## ステップ 2：File > Import でインポートする

1. **File > Import** を開き、モデルファイル（例：`.obj`）を選択します。
2. ファイルを選択すると、ダイアログ右側の **Options** に **Asset Importer** の変換オプションが表示されます：

    ![OBJ インポートオプション](images/04_obj_import_options.png)

    | 主な項目 | 説明 |
    |---|---|
    | **Import Materials** | マテリアル（.mtl / テクスチャ）を取り込むか |
    | **Use Meter as World Unit** | モデルの単位をメートルとして扱うか |
    | **Create '/World' Default Prim** | `/World` をデフォルトプリムとして作成するか |
    | **Up-axis** | モデルの上方向の軸（既定はファイルの設定に従う） |
    | **Destination（Path）** | 変換後の USD の出力先。空欄ならモデルと同じフォルダ |

3. **Import** をクリックすると、モデルが USD に変換されてステージに追加されます。

!!! note "インポートの仕組み"
    このインポートでは、元のファイルと同じフォルダ（または Destination で指定した場所）に**変換された USD ファイルが生成され**、現在のステージにはその USD への参照（正確には**ペイロード**：通常の Reference と似ていますが、必要になるまで読み込みを遅延・解除できる参照方式）としてプリムが追加されます。元のモデルファイルが書き換えられることはありません。

!!! tip "単位とスケールに注意"
    ステージとモデルの単位が異なる場合、「Mismatched units found ...」という通知が表示され、プリムに `unitsResolve` 系の補正（スケールや回転）が自動で追加されます。また、データセット配布のモデルは正規化された単位（1 前後の大きさ）で保存されていることが多く、実寸とは一致しません。インポート後に Property パネルの **Transform > Scale** で実際の物体サイズに合わせて調整してください。

## ステップ 3：物理プロパティを設定する

インポートした直後のモデルは見た目だけの存在で、物理シミュレーションには反応しません。シミュレーションで使うには：

1. モデルのプリムを選択し、Property パネルの **+Add** ボタンから **Physics > Rigid Body with Colliders Preset** を適用します（重力で落下し、他の物体と衝突する「動く剛体」になります）。
2. 動かない障害物として使う場合は、代わりに **Physics > Colliders Preset** のみを適用します。
3. 適用後、Property パネルに **Rigid Body** や **Collider** のセクションが追加されていることを確認します。必要に応じて質量やフィジックスマテリアル（摩擦係数など）を設定します。

## ステップ 4：シミュレーションで確認する

1. 地面がない場合は **Create > Physics > Ground Plane** で地面を追加します。
2. **PLAY** ボタンでシミュレーションを開始し、モデルが地面に着地・静止することを確認します。

物理プロパティの設定方法の詳細は [Core API チュートリアル 7: 属性の追加](../core_api/07_adding_props.md) を参照してください。

## まとめ

このチュートリアルでは以下のトピックを扱いました：

1. **File > Import** による一般 3D モデル（OBJ など）のインポートと Asset Importer のオプション
2. **単位・スケール**の自動補正と実寸あわせ
3. **Rigid Body with Colliders Preset / Colliders Preset** による物理プロパティ設定
4. **Ground Plane** を追加したシミュレーション確認

これで「インポート・エクスポート」チュートリアルシリーズは完了です。
